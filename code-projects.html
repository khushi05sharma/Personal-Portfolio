Olive & Thyme

A full-stack recipe sharing platform — discover, share, and manage recipes with health-goal filtering, JWT auth, and real-time notifications.Containerized application using Docker and Docker Compose. Multi-stage builds for both frontend (React + Nginx) and backend (Express + Node.js).

JWT auth · Debounced Spoonacular API · Real-time notification system · Deployed on Vercel + Render

Key Features

  • Health Goal Filtering — Diabetic Friendly, Heart Healthy, and more mapped to real Spoonacular diet params
  • User Authentication — JWT tokens, bcrypt password hashing via Mongoose pre-save hook, protected routes
  • Recipe Management — Upload recipes with ingredients and instructions stored in MongoDB
  • Notification System — Real-time feed created when someone likes or comments on your recipe
  • Forgot Password Flow — Secure token with expiry time, email via Resend API
  • Performance — Debounced search and filters to keep API calls efficient

EmoTracker 🌸

A minimal, soothing mood-tracking app built with React and Vite, enhanced with AI-powered journaling insights via the Gemini API and with a lightweight Express backend to securely handle API requests. EmoTracker helps you express your emotions, journal your day, and receive personalized reflections — one entry at a time, in a calm pastel space and persists entries across sessions with localStorage.

Features

  • Write a short note and select an emotion with emoji labels
  • Receive AI-generated encouragement, reflection, and a suggestion based on both your entry and emotion
  • Automatic date stamping on every entry
  • Separate Past Notes page to reflect on emotional history, including saved AI insights
  • HashRouter-based navigation for smooth GitHub Pages deployment
  • Fully responsive — works on all screen sizes
  • Soft pastel UI designed for calm, distraction-free journaling
